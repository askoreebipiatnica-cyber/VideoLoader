# VideoLoader — качалка видео

Расширение для Chrome / Vivaldi / Edge / Brave / Opera / Яндекс Браузера (Manifest V3).

## Как пользоваться
1. **Строка + «Скачать»**: вставьте ссылку на видео или страницу. Пока работает — в статусе видно этап («Открываю страницу…», «Ищу video_url…», «Проверяю API Instagram…», «Качаю…»). Порядок: помощник → прямой файл → вкладка → страница → Instagram API (`video_versions`) → TikTok → embed → пойманное. Скачивается только цельный файл — мусор не сохраняется.
2. **Галочка «Авто-сохранение»** (по умолчанию выкл): когда смотрите видео, цельный файл сохраняется сам, без кнопок. Короткие (<3 сек), эфиры и мелочь (<256 КБ) пропускаются.
3. **«Стоп»**: останавливает разбор/закачку. Закрытие окна закачку не прерывает.
4. **Темы**: светлая / тёмная / как в системе.
5. **«Скачанное»**: последние 7 файлов, «Показать» открывает в папке, ✕ удаляет файл с диска, «Очистить» чистит список (файлы целы).

## Установка (без сборки)
1. Распакуйте `videoloader.zip`.
2. `chrome://extensions/` → **«Режим разработчика»**.
3. **«Загрузить распакованное расширение»** → папка `videoloader` (где `manifest.json`).
4. Закрепите иконку на панели.

## Локальный помощник (для Instagram/TikTok/YouTube)
Расширение сначала пробует скачать через помощника — это тот же подход, что у сайтов-качалок, но сервер крутится у тебя на машине:
1. Дважды кликни `D:\AI\work\tools\helper\run-helper.bat` (должно висеть запущенным; в popup внизу будет «помощник вкл»).
2. Жми «Скачать» как обычно — помощник тянет видео через yt-dlp с куками твоего Chrome.
3. Не запущен — расширение молча идёт по встроенной цепочке.
Файлы: `D:\AI\work\tools\yt-dlp.exe`, сервер `D:\AI\work\tools\helper\server.js`, готовое складывается в `helper\out` (чистится само, старше часа).

## Честные ограничения
- Качается только цельный MP4/WEBM. Если сайт отдаёт исключительно фрагментированный DASH-поток без цельного файла — расширение так и скажет, битый файл не подсунет.
- HLS (`.m3u8`) / DASH (`.mpd`) — плейлисты, а не видео.
- YouTube в высоком качестве отдаёт только DASH — кнопкой забирается то, что отдаётся цельным.
- Для приватных постов используется ваша залогиненная сессия браузера.
- Сайты меняют разметку — тогда нужно обновление.

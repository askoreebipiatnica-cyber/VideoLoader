Установка за минуту

  1. Скачай ZIP из Releases и распакуй.
  2. Открой chrome://extensions/ и включи «Режим разработчика».
  3. «Загрузить распакованное расширение» → папка videoloader.
  4. Закрепи иконку. Или через консоль:
git clone https://github.com/askoreebipiatnica-cyber/VideoLoader.git

Честные ограничения

  • Только цельные MP4/WEBM. Нет цельного файла — скажет, битый не подсунет.
  • HLS (.m3u8) / DASH (.mpd) — плейлисты, а не видео.
  • Топ-качество YouTube — только DASH, забирается цельное.
